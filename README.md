# Superstore Sales Dashboard

## Project Overview
This project is an interactive **Sales Dashboard** created using Excel/Power BI to analyze and visualize retail sales data.  
The goal of this dashboard is to convert raw data into meaningful insights that help in better business decision-making.

---

## Objectives
- Analyze overall sales performance  
- Identify top-performing products and customers  
- Track monthly and regional trends  
- Provide a user-friendly and interactive dashboard  

---

## Key Features
- Total Sales, Profit, and Orders Overview  
- Monthly Sales Trend Analysis  
- Top 10 Customers and Products  
- Region-wise Sales Performance  
- Category & Sub-Category Analysis  
- Interactive Filters (Slicers)  

---

## Tools & Technologies Used
- Microsoft Excel / Power BI  
- Data Cleaning & Transformation  
- Pivot Tables / DAX  
- Data Visualization  

---

## Dataset
- Superstore Sales Dataset (Sample retail data)  
- Includes: Orders, Customers, Products, Sales, Profit, Region  

---

## Insights Gained
- Identified top revenue-generating products  
- Analyzed profit trends across different regions  
- Found seasonal patterns in sales  
- Discovered high-value customers  

---

## How to Use
1. Download the file from this repository  
2. Open in Excel / Power BI  
3. Use filters and slicers to explore the dashboard
